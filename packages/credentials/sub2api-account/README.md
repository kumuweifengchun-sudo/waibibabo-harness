# @deepseek-ai/dsh-sub2api-account

## 概述

通过平台邮箱和密码、身份验证器验证码，或系统浏览器中的明确授权登录。登录后自动选择首个可用分组并加载模型，本地任务费用计入平台账号。账号页面与登录弹窗共用产品标志，展示账号身份、剩余额度和用量；侧栏用户名右侧显示额度，默认每 60 秒自动刷新，失败时保留上次金额并标记。账号、侧栏和使用日志中的额度统一四舍五入并固定显示两位小数，原始计费数据保留完整精度。轮询间隔由 `accountRefreshIntervalMs` 配置。凭据保存在本地 Host；渲染进程只接收账号资料和登录进度。

## 使用此包

[歪比巴卜组合包](../../bundle/waibibabo/README.md) 在桌面配置中挂载此包。其他组合需要 credentials、WebServer 和 LLM 服务，以及使用数字回环地址和明确端口的 HTTP 监听器。平台必须在网站和网关共用的 HTTPS 源站提供桌面授权接口。

```yaml
- name: '@deepseek-ai/dsh-sub2api-account'
  config:
    platformOrigin: https://www.waibibabo.com
    productName: 歪比巴卜
```

`allowLoopbackHttp: true` 仅允许数字回环开发服务器使用 HTTP。`protocol` 默认为 `auto`：OpenAI 模型使用 Responses，Claude 使用 Messages，DeepSeek 使用 Chat Completions，Gemini 使用 Gemini 原生接口。模型目录提供支持端点时，自动选择限定在这些端点内。部署也可显式选择四种协议之一作为默认值。模型预算、请求时限、登录时限和提前续期时间在 [Config](src/config.ts) 中配置。

在账号页面刷新资料或退出登录，在“模型”模块选择分组、协议和推理线路。首次登录自动选择列表中的第一个分组和该组的第一个模型，可直接开始对话。手动选择的分组和模型在刷新、重启后保留；原分组不可用时选择当前列表的第一个分组。用量汇总失败会单独提示，不阻止读取账号和使用模型。退出登录会移除本地登录状态，并请求服务端撤销授权。远程撤销失败时保留可见提示，同时提供平台设备授权页面入口。

“账号线路”在登录弹窗和平台账号页设置，默认自动选择，也可指定 `platformOrigin` 或 `accountOrigins` 中的可信 HTTPS 地址。自动检测并行读取公开桌面配置，选择首先返回且授权资源与 `platformOrigin` 完全匹配的线路；检测不发送密码或令牌。手动选择只检测指定地址，失败时保留选择并提示，不自动改用其他地址。选择保存在本机的 `sub2api-account/connection` 记录中，退出账号和重启后保留。OAuth 资源与已保存的授权身份保持原源站。连接失败后，下次账号操作重新检测；已提交的登录、续期、订单和生图请求不会自动重发。超时、平台服务错误与授权失效分别提示。

每个模型旁可手动选择协议或恢复自动选择。设置按分组和模型保存在当前登录记录中，刷新令牌、重启和切换分组不会覆盖它，退出登录时清除。已准备的请求保持原协议，设置对后续请求生效；不会在发送失败或已有输出后改用其他协议重发。

平台的 Responses 模型默认使用 HTTP/SSE 流式传输，可在每个模型旁选择“流式（默认）”或“WS”。选择按当前账号、分组和模型保存，刷新、切换分组和重启后保留，退出登录时清除，从下一次请求生效；正在传输的请求保持原方式。流式兼容性更好、通常更稳定，但重复请求的传输开销较多；WS 复用连接可减少开销、改善速度，少量请求可能因网关兼容性或连接中断而报错，实际效果取决于网络和网关。

WS 在同一会话中复用连接，默认每次发送完整历史，由现有适配器处理推理、工具调用和用量。`responsesIncrementalHistory` 默认关闭；仅对已验证支持 [Responses WebSocket 接续协议](https://developers.openai.com/api/docs/guides/websocket-mode)的网关设置为 `true`，此时历史与请求选项一致才自动发送 `previous_response_id` 和新增输入。连接、密钥、会话或上下文改变时仍发送完整历史，压缩后的上下文不会接续旧链。增量缓存仅在内存中保存历史指纹与响应标识，不持久化聊天内容；省去重复上传不代表减少平台计费 Token。

复用连接前通过 Ping/Pong 检查存活状态，每次检查增加一个网络往返。WS 握手不支持、握手失败或提交前健康检查失败时回退 HTTP/SSE；平台明确返回 `websocket_unavailable` 与 `http_fallback: true`，或在响应开始前以 `websocket_connection_limit_reached` 拒绝请求时，也可使用完整输入回退。仅在未收到响应事件时，`previous_response_not_found` 允许一次完整历史重试。

提交后发生 1011、1006 等连接中断时，普通同步模型请求以结构化 `TRANSPORT` 失败交给 Agent 重试策略，默认最多重试五次并指数退避；冷却期间重试使用完整历史走 HTTP/SSE。失败尝试与关闭原因进入 Session 重试记录，未完成的输出不会成为成功消息，已完成的本地工具操作不会重放。取消会停止恢复，直接调用模型流仍只执行一次请求。服务器托管工具、后台任务、外部 `previous_response_id` 或策略拒绝保留为 `RESPONSES_OUTCOME_UNKNOWN`，不进入默认重试。断线请求的上游生成和计费结果仍可能未知，重试可能产生额外用量。

`responsesTransport` 配置默认值为 `sse`；显式配置 `auto` 会让未单独设置的模型优先使用 WS，逐模型选择优先于此部署默认值。WS 握手及复用前健康检查使用 `connectionProbeTimeoutMs`，默认 5 秒；`responsesSocketIdleMs` 默认保留空闲连接 2 分钟，`responsesSocketLimit` 默认保留 16 条连接，`responsesFallbackCooldownMs` 默认在回退后等待 1 分钟再尝试 WS。账号、分组和线路变化使旧连接停止复用，退出或关闭客户端时清理；并发请求使用独立连接。只有 Responses 支持此选择；切到其他协议时隐藏控件，切回 Responses 时恢复保存的选择。Chat Completions、Messages、Gemini 与独立生图接口保持原传输方式。

对话模型菜单按模型能力显示“推理等级”，使用现有会话选项保存选择。平台目录的 `supportsReasoningEffort` 和 `reasoningEfforts` 优先；未声明时读取内置模型目录。OpenAI、Claude、DeepSeek 和 Gemini 按各自协议发送档位、思考开关或预算，保留平台模型名称和网关地址。未选择档位时沿用提供方默认行为。

“默认模型容量”管理当前平台账号的全局上下文、输入和输出预算；每个分组内的模型可单独覆盖，未覆盖或恢复全局的模型随全局设置变化。默认上下文 256K、输入 224K、输出 32K，提供 256K、475K、1M 预设及自定义整数，1K 为 1024 Token。输入和输出之和不得超过上下文预算；较低输入预算通过有效上下文窗口让压缩提前发生。输出上限明确传入模型请求，包含协议计入输出的推理消耗。自动压缩读取实际模型预算，默认按输入余量调整压缩预留，并限制摘要输出；显式压缩配置仍按配置执行。平台模型允许提交图片，是否接受由实际端点判断。全局值与按分组、模型保存的覆盖值随当前登录记录保存，从下一次请求生效；实际支持范围仍由平台模型决定。部署默认值分别为 `defaultContextWindow`、`defaultMaxInputTokens` 和 `defaultMaxTokens`，未指定输入值时从上下文预算中扣除输出。

设置左侧的“使用日志”读取当前账号的全平台用量记录，支持日期、完整模型名称、分组、流式方式和分页。统计由服务端按同一筛选条件计算；统计失败时明细仍可查看，总计显示为不可用并提示刷新。详情显示请求端点、Token、缓存、费用和耗时。日期按本机时区解释，最多查询 90 天。需要服务端提供 `/api/v1/desktop/usage/records` 和 `/api/v1/desktop/usage/stats`，缺少接口时显示升级提示，不影响登录和对话。

“模型线路”在模型设置中独立管理，默认自动选择。客户端使用分组的短期推理密钥检测平台公布的 HTTPS 线路，选取最先返回有效且非空模型列表的地址；账号线路不决定模型地址。检测结果按分组复用，点击“应用并重新检测”可重新选择。账号和模型的检测时限均由 `connectionProbeTimeoutMs` 配置，默认 5000 毫秒；数字回环 HTTP 仅在显式开发配置中参与自动检测。手动选择固定地址并随登录记录保存，模型目录、对话和生图均遵循该选择；HTTP 推理线路需明确确认。已开始的模型请求保留其原地址，切换不重发已有请求。账号授权、额度、使用日志、订阅和发票只走账号线路，推理线路不会收到桌面授权令牌。

侧栏“生图”使用开启生图权限的分组，支持模型名称、提示词、数量和尺寸。可通过“上传参考图”多选 PNG、JPEG 或 WebP，查看缩略图并逐张移除；有参考图时通过 `/v1/images/edits` 提交图片和提示词，无参考图时调用 `/v1/images/generations`。模型需支持相应操作。参考图默认最多 16 张、合计 20 MiB，由 `imageReferenceMaxCount` 和 `imageReferenceLimitBytes` 配置；客户端读取前与 Host 提交前均校验，Host 还核验图片签名。读取期间禁用生成，整批读取失败时保留已有参考图。生图分组独立于对话分组。参考图、生成图片和草稿在当前客户端账号会话中保留，切换面板不会丢失，退出或重启后清除；需要保留的结果应主动下载。

生图页面在宽窗口中并排显示生成设置和结果，窄窗口中上下排列。模型下拉列表读取所选生图分组的 `/v1/models`，与对话分组独立；通过“手动输入”填写模型名，切换输入方式保留草稿。比例预设映射为明确的像素尺寸，也可分别填写宽高。结果以固定高度缩略图展示，点击可放大；优化后的提示词可展开查看。生成中或失败时保留上次结果；下载显示进行中状态，桌面保存完成后显示路径，取消与失败分别提示，浏览器只确认下载已发起。

“前往平台充值”在浏览器打开平台主站的 `/purchase`，由网站完成余额充值；链接不携带桌面授权令牌。客户端“充值与订阅”展示套餐、订阅和订单，平台公告与套餐说明按 Markdown 渲染。支付方式仅在在线支付已开启、有可购买套餐且存在多个可用渠道时显示；单一可用渠道直接用于订阅订单，没有可用渠道时显示提示并禁用创建按钮。创建订阅订单时就近展示进度或失败原因，成功后滚动并聚焦本次订单，用户点击支付链接或扫码付款。客户端只按服务端核验结果更新状态。创建订单或生图结果未知时不会自动重发，先核对记录再决定下一步。

“发票申请”支持列表、详情、新建、修改待开具申请及附件下载。实际付款金额最低为人民币 200 元，手续费和开票总金额由服务端计算。额度购买与发票手续费截图各至少一张，PNG/JPG 每张最多 20 MiB，两类合计最多十张。未确认的提交保留原字段和幂等键，重试不会创建重复申请；退出或重启前应先核对申请记录。

歪比巴卜桌面端固定使用中文，账号介绍只维护中文文案。元数据中的 `en` 项复用中文以满足加载器的基础回退字段，不提供英文界面。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现细节 — 点击展开</summary>

浏览器登录使用随机 state、PKCE S256 校验器和一次性回环回调。回调路由允许未登录浏览器访问，并通过 state 与一次性授权码校验请求。密码登录只获取临时网站会话来批准相同的桌面授权；密码和临时网站令牌均不持久化。桌面授权有独立资源标识，不能访问网站管理功能或管理 MCP。

凭据提供方在 `sub2api-account/desktop` 保存轮换授权，原子记录更新串行处理多个 Host 进程的续期。推理使用选定分组独立的十分钟 API 密钥租约，仅驻留内存。模型路由标识包含账号和分组 ID；已准备的路由不能获取另一账号的凭据。明确的认证拒绝会移除当前授权，网络失败则保留最近成功读取的账号资料。

销毁插件会中止未完成请求，移除回调和模型注册。账号状态通过生成的 Remote 暴露；服务不会向渲染进程返回令牌、密码或推理密钥。

客户端的 Remote 注册独立于页面服务的注入作用域。页面服务卸载先结束订阅和清除账号内存，避免其释放过程等待同一队列中的 Remote 注销。

已准备的模型请求在账号插件卸载后不能再取得密钥。本地凭据写入失败会显示存储错误；退出时清理失败不会报告已完成退出。

</details>

<a id="model-experience"></a>
## 模型体验

无，因为这些账号页面和生图操作不进入 Agent 对话，不新增工具、提示词、Session 事件或工具结果。协议选择决定现有对话请求的序列化方式，生图由用户在独立面板提交。

#### KV Cache 影响

切换协议可能改变消息和工具的序列化，不能保证复用旧请求的缓存；账号与用量查询本身不改变模型请求前缀。

## 已知限制与延后工作

<a id="known-limitations-and-deferred-work"></a>

- 要求人机验证的部署使用浏览器授权；密码表单不会绕过平台验证。
- 本地凭据提供方使用私有文件存储，不使用操作系统加密。同一系统用户运行的程序可以读取它。
- 撤销授权会阻止租约续期。服务端清理失败或其他服务端操作撤销授权时，租约最多仍有效十分钟。
- 容量设置不能扩展上游模型的实际限制；超出支持范围时需调低预算。此包不提供平台技能目录，无法识别且平台未声明推理能力的模型使用提供方默认行为，不显示推理等级选项。
