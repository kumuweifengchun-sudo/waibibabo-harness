# 工作区目录

[English](guide.md) | 中文

## 变更

`Workspace.path` 与 `WorkspaceView.path` 表示当前主要目录，修改文件夹后可以变化。稳定标识应使用 `WorkspaceId`。`directories` 列出授权文件夹，首项为主要目录。原有单目录记录无需手动转换即可读取。会话头部和对话日志不变，历史主要目录用于保留会话归属，不保留其文件系统授权。

挂载工作区注册表时，沙箱策略在每次操作中解析当前工作区目录，包括子代理调用。运行中的任务和未关闭的终端会阻止目录修改。新会话与工作区分叉使用主要目录，已有会话保留当前工作目录。

## 迁移

1. 同时更新宿主与客户端。消费方不能再把 `path` 缓存为不可变标识或完整可写目录集合。旧宿主未返回 `directories` 时表示 `[path]`。
2. 在工作区菜单中点击“编辑”，添加文件夹并选择主要目录。受限角色需要 `workspace/edit` 才能修改目录授权，`workspace/rename` 仍仅修改名称。已有所有者部署无需修改配置。部署级 `additionalWritableRoots` 仍是独立授权。
3. 重启后确认配置的目录仍在，并确认新会话从主要目录开始。该数据目录需继续使用新版宿主，旧宿主重写工作区记录时无法保留多目录元数据。
