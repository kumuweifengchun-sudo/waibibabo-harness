# Waibibabo Harnesss 桌面账号与数据目录

## 变更

产品简称统一为 WSS，发布版本从 0.1.0 开始，与底层运行时的工作区包版本独立。侧栏、会话首页、关于窗口、安装元数据和 `wss/<产品版本>` 请求头使用同一产品身份；品牌配置位于 `packages/llm/llm/src/waibibabo-product.json`。现有数据目录、配置键、包名和会话格式保持兼容。

平台模型的默认协议改为自动选择：OpenAI 使用 Responses，Claude 使用 Messages，DeepSeek 使用 Chat Completions，Gemini 使用原生 Gemini 协议；模型列表明确声明支持端点时，自动选择限定在这些端点内。“模型”模块集中管理分组、逐模型协议覆盖和 API 线路；覆盖值随当前登录记录保存，重新启动和切换分组后仍生效，退出登录时清除。原有 `protocol` 配置仍可显式指定默认协议。

模型默认预算为上下文 256K、输入 224K、输出 32K，输出上限明确发送给模型。已有登录记录缺少可选 `modelLimits` 时使用这些默认值；新增可选 `modelLimitOverrides` 按分组与模型保存独立预算，缺失时继承全局；可在模型设置选择 256K、475K、1M 或自定义预算，输入与输出之和不得超过上下文。产品组合使用 WSS 的默认助手身份，禁用上游源码与 GUI 开发上下文；声明完整提示词的预设仍使用自定义内容，已保存的历史内容不改写。

余额充值改为浏览器打开平台 `/purchase`，客户端保留订阅和订单查询。统计接口失败不再阻止显示使用日志明细；配套后端需要更新统计 SQL 修复，无新增数据库迁移。

平台账号页只保留账号信息。新增独立生图面板以及充值订阅、发票设置页，要求配套服务端提供 `/api/v1/desktop/gateways`、`payment/*`、`invoices/*` 路由，已部署桌面授权的实例不增加数据库迁移。已有登录记录可直接读取，未保存模型线路时改为独立自动检测；已有手动模型地址继续生效。账号线路支持登录前选择，以独立的本机记录保存，退出账号后保留；不改变 Session 格式或 OAuth 签发源。Remote 调用方以 `GatewayView.selected: null` 表示自动模式，通过 `setGateway(null, false)` 恢复自动选择；`active` 表示当前对话分组的实际地址。

使用日志页面通过新增的 `/api/v1/desktop/usage/records` 和 `/api/v1/desktop/usage/stats` 查询网站记录，服务端需要同步更新，不需要额外数据库迁移。桌面组合移除官方 Session Log 上传设置、上传服务和 Session 遥测导出器。

桌面界面固定中文，忽略其他已保存的界面语言，不再显示语言切换选项。产品介绍与接入说明只提供中文。

此发行版在基础 bundle 和 Web bundle 之后加载歪比巴卜 bundle，启动 desktop 配置。账号界面登录 Sub2API。此桌面组合禁用 DeepSeek 平台账号界面和产品遥测。普通 CLI 与 Web 配置模板保留现有组合。

桌面应用名称为 Waibibabo Harnesss，默认使用 `~/.waibibabo`，而非上游的 `~/.dsh` 数据目录。应用标识为 `com.waibibabo.desktop`，安装包名称以 `waibibabo-harnesss` 开头。此发行版不注册上游应用的操作系统 URL 关联，也不内置其更新源和强制更新服务。现有上游数据不会被移动或删除。

自动压缩新增 `adaptiveBudget`：未显式设置压缩预留或摘要输出上限时默认启用，按实际输入预算缩小预留，并把摘要输出限制在模型输出预算及可保留空间内；原有显式设置保持固定预算，可显式关闭自适应。平台模型允许上传图片，实际支持由推理端点决定。

账号与日志将美元文案改为额度，侧栏自动刷新剩余额度。生图新增分组模型下拉、手动输入、比例与宽高、缩略图放大和保存反馈。网页设备授权支持删除、批量撤销、批量删除及 IP 记录，服务端需要新增迁移 `256_desktop_device_activity.sql`；已有授权在下次请求时开始记录 IP。密钥使用 `WSS · 电脑名 · 分组 ID`，旧自动名称在续期时升级，自定义名称保留。

## 迁移

平台 Responses 模型默认优先使用 WS，握手不支持时回退 HTTP/SSE；需要固定原传输方式时，在账号插件配置中设置 `responsesTransport: sse`。平台反向代理需转发 WS Upgrade；配套后端增加首次选号未执行时的明确回退标记，无需数据库迁移。旧后端在接受连接后直接断开且未明确拒绝时，客户端会报告结果未知，不会盲目重发。

1. 部署配套的 Sub2API 服务端并应用桌面 OAuth 数据库迁移，将服务端前端地址设为公开 HTTPS 源。按[账号包部署说明](../../../../packages/credentials/sub2api-account/README.md#use-this-package)配置。
2. 启动桌面应用，使用平台邮箱密码或浏览器授权登录。选择一个可用模型分组，确认对话选择器显示对应模型。
3. 独立安装保留独立数据目录。若明确需要复用已有数据目录，先备份该目录，再在启动前设置 `DSH_HOME`。应用会遵循此显式配置。
4. 私有开发服务设置 `WAIBIBABO_PLATFORM_ORIGIN`；仅在使用数字回环地址的 HTTP 服务时，设置 `WAIBIBABO_ALLOW_LOOPBACK_HTTP=1`。切换签发源后需要重新登录。
